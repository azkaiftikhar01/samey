Turn the Slack thread into a checklist the next person can run

Somebody rotated the API keys at 2am and explained it across forty messages. NovaFlow pulls the commands and decisions out of that thread and gives the next on-call engineer a numbered runbook with owners.

See an example runbookPricing

How it works

  1. Pick a thread. Add the NovaFlow app to a channel and react to a thread with the runbook emoji, or paste its link.
  2. Review the draft. NovaFlow lists the commands, links, and decisions it found, in order. You remove the dead ends and confirm the owner of each step.
  3. Run it next time. The runbook lives at a stable link. Whoever is on call ticks steps off, and the thread it came from stays linked for context.

Questions people ask

Does NovaFlow read every channel?

No. It only reads threads you send it, and only in channels where the app has been added.

Can we edit a runbook after it is created?

Yes. Every edit is kept in the run history, so you can see what changed after an incident.
